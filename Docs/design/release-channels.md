# 发布包下载通道

特别版的安装包接近 1.1 GB（Kachina 安装器 577 MB + 免安装 7z 522 MB），下载体验主要取决于通道给不给直链、限不限速。这里记录各家的实际情况和选型结论，改流水线前先看这一页。

## 结论

| 用途 | 通道 | 状态 |
| --- | --- | --- |
| 主通道 | GitHub Releases | 已在用。国内直连慢，但资产永久、可校验 SHA256 |
| 国内主通道 | 123 云盘（WebDAV 或开放平台） | 已在用，**必须配 Secret 才真的传**，见下 |
| 国内备选 | 天翼云盘 | 官方开放平台，个人开发者可申请，宣称不限速 |
| 直链兜底 | 蓝奏云（优享） | 单文件上限大、直链可 wget，但没有官方 API |
| 可选加速 | Cloudflare R2 | 出站免费、10 GB 存储免费，需要信用卡验证 |

## 123 云盘：不是限速，是没传

123 云盘官方口径是「免费用户上传下载都不限速」，这一点和我们观察到的一致。7.5 那次「上传到 123 云盘」步骤只跑了 1 秒，原因不是被限速，而是**没有配置任何凭据**，脚本走了「未配置 → 直接成功退出」的分支；步骤上又挂着 `continue-on-error: true`，所以运行摘要里看不出来。

配好下面任意一组 Secret 就会真的传：

- WebDAV（历史会员权益，优先走这条）：`PAN123_WEBDAV_USER`、`PAN123_WEBDAV_PASS`
- 开放平台（需要企业开发者）：`PAN123_CLIENT_ID`、`PAN123_CLIENT_SECRET`，可选 `PAN123_PARENT_ID`

传完要回头看一眼运行摘要的 `### 123 云盘：<状态>`，那里现在会明确写「未配置 / 无产物 / 成功 / 失败」，不再只显示一个绿色的勾。

## 不依赖网盘的加速

- **Cloudflare R2**：10 GB 存储 + 每月 100 万次 A 类 / 1000 万次 B 类操作免费，**出站流量不计费**。1.1 GB 的两个包放得下，`r2.dev` 或自定义域名都能直接给下载链接。注册要信用卡验证（不扣费）。
- **GitHub 加速前缀**：`ghproxy` 一类的反代只适合临时救急，不承诺稳定性，不要写进客户端更新源。

## 落地顺序

1. 先配 123 云盘的 WebDAV 凭据。这是成本最低的一步，配完就能验证 `upload-123pan.yml` 是不是真的在传。
2. 需要第二个国内通道时再接天翼云盘：它的开放平台文档里上传分「一次性 PUT」和「断点续传」两套，1 GB 的包走断点续传，和现在的分片上传脚本结构接近。
3. R2 只做镜像，不做主源：客户端更新检查仍然只认 GitHub Releases，避免出现两条版本线。
