## 本版改动

### 日志上传挪到能看见的地方

7.7 加了这个功能，但位置放错了：藏在「启用遮罩窗口 → 日志遮罩」这张卡片的最底下，和「日志区域背景色」「日志字号」混在一起。那张卡片默认折叠，子卡片也折叠，正常人翻不到。

现在「软件设置」页第二张卡就是「日志」，一眼能看到：

- 打开日志目录
- 写入日志文件的详细程度
- 生成诊断包
- **把日志发送给开发者**（不上传 / 仅手动上传 / 自动上传）
- **上传当前日志**

功能本身没变：发送前脱敏，先压缩再签名，只发最新日志尾部 8MB，失败只写一条警告，不弹窗。

### 说明

如果你在 7.7 里已经找到过上传按钮，这版不用装——除了位置，行为完全一样。装了的用户配置不受影响，上传方式那个选项会原样保留。
