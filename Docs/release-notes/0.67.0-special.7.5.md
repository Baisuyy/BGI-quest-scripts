## 本版改动

### 热更新是真的能用了

之前几版写的「增量更新」其实一次也没生效：流水线里 `gh release list --json` 的多行输出被 PowerShell 逐行解析，第一步就抛异常，而这一步配了 `continue-on-error`，失败只表现为发布页少一个 zip。7.2、7.3、7.4 都是这样静默丢的。

- 增量包重新生成，命名 `BetterGI_v<新版本>_patch-from-<旧版本>.zip`，只做相邻版本
- 下载走内置下载服务：主地址直连、失败换镜像、断点续传
- 解压后逐文件核对 SHA256，对不上不装
- 退出后由独立脚本备份、覆盖、删掉新版已移除的文件、拉起新版；中途失败回滚
- `User/**` 三道都挡：构建不进包、客户端解析剔除、覆盖脚本动手前再拦一次
- 没放出增量包时，弹窗直说原因并给完整包链接

### 米游社绑定改成扫码

- 私聊发「绑定米游社」，回一张二维码；米游社 App 扫码确认后再发一次同一句，登录态写入配置
- 多角色列出昵称 / UID / 服务器，回「绑定米游社 2」选定，5 分钟内有效
- 桌面端「设置 → 通用 → 远程任务」新增「扫码绑定米游社」，走同一套逻辑
- 群聊直接拒绝：二维码谁扫都算数，登录态又是全局配置
- 票据只在内存里待三分钟、不落盘；日志只写脱敏后的账号字段

### AI 助手

- 先分清「让我干活」和「问我一句」，不再把闲聊当任务下发
- `done(success = true)` 需要画面依据；同工具同参数两轮没进展必须换法
- `list_paths` / `read_path` 直接读脚本里的路线点，不用真跑
- 地图追踪按段记进度，被强杀后从断点接上
- `review_script` 只读体检：固定文案日志、写死队伍名、写文件、绝对路径、外链
- 日志分四档落盘；出现 `[ERR]` 自动打诊断包到 `log/diagnostics`，不自动上传

### 跟进上游

- 传送锚点 797 → 840
- 邀约拆成 `HangoutConfig` / `hangout.json` 三层，选项识别与自动跳过同步
- 旧邀约配置存的是角色名，新结构对不上，打开设置页会落到第一个结局，重选一次即可

### 修复

- 发版说明里的「基于上游」被写成特别版版本号
- 每日上游同步不再自动发版，避免出现 `special.100` 这种号把版本线搅乱
