## 本版改动

### 更新改成「你说了才更」

以前启动 8 秒后自己查一遍、有新版本就弹窗。开机时被打断，而且不打招呼就升级，不是所有人都想要。现在：

- 启动不查、不弹窗
- 想升级就两句话：在 QQ 里发「更新」，机器人检查并下载、逐文件校验，回来告诉你有多大；再发「重启更新」，它退出、换文件、自己回来，中间离线十几秒
- 桌面端还是点菜单里的「检查更新」，行为不变
- 没有增量包时只说这次只能下完整包，并给发布页，不硬装

更新只由人开口，模型不会自己顺手升级。

### 任务结束只发有用的东西

以前不管成没成都截一张当前画面。成功的截图就是角色站在终点，看不出跑没跑对，白占带宽。

- 成功：只发结果与用时，外加过程中出现的告警（从日志里挑，最多 5 条）
- 失败 / 取消：附一张当时的画面，那就是问题现场
- 一个任务连发好几条告警时只看最后几条，不会刷屏

### 发版说明只写这一版

Release 页以前每次都贴一整篇「与官方版的差异」，本版改了什么埋在最上面一小段。现在每版单独写一份，说明里只有这一版的改动，安装与升级两段固定收尾；完整能力介绍留在 `README-SPECIAL.md`。

没写说明时按提交标题兜底，不会再出现空正文。

### 123 云盘

- 上传结果写进运行摘要：跳过（没配凭据）、已上传（目录 + 文件）、失败（原因），不再只留在日志深处
- 新增「补传 123 云盘」工作流：填个版本号就能把已发布的包补镜像一份，不用重跑 40 分钟的构建

### 修复

- 「更新脚本」不会再被当成更新软件：只有整句「更新」「升级」才触发
