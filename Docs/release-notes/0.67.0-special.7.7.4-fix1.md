## 本版改动

这一版没有新功能，修的是 7.7.3 里**静默消失**的东西。

### QQ 机器人、定时任务回来了

11-26 同步上游时，`App.xaml.cs` 里整块特别版注册被覆盖，`QqBotService`、`RemoteScheduleService` 等十几个服务不再启动。代码文件一个没少，所以编译照过、同步检查四项全绿——只是运行时没人调用它们。表现就是设置页里找不到配置项，机器人在线与否都没反应。

现在这些注册补齐了：

- **QQ 机器人**：AppId / Secret、OpenID 白名单、对话人格、截图质量、自由操作，都在「设置 → 远程任务」卡片里
- **定时任务**：按时间点或树脂阈值自动触发，和手动点开始走同一条执行路径
- **米游社扫码绑定**：网页端扫码拿登录态，不用再去开发者工具里抄 Cookie

### 「日志」卡片回来，落盘策略也回来了

同样是同步被吃掉的：

- 设置页的**日志卡片**：打开日志目录、选落盘级别、生成诊断包、上传当前日志
- **旧日志归档**：升级后老格式（行首只有时分秒）和新格式混在一个文件里读不出先后，启动时会把旧文件改名分开
- **重复日志抑制 + 异常栈去重**：同一条错误反复重试时只展开一次
- **出错自动攒诊断包**：日志尾部 + 环境 + 脱敏配置，反馈时直接拖出去

落盘级别可选，长时间只关心报错的话设成 Error，一天几百万行 Debug 既占地方又让 grep 变慢。

### 插件不再被误判「需要更高版本」

特别版的版本号是 `0.67.0-special.7.7.4-fix1`，按 SemVer 它低于 `0.67.0`。原来的兼容性检查直接拿整串比较，于是**任何用官方 SDK 编译的插件**（`sdk_version: 0.67.0`）都会被判成「需要 BetterGI 0.67.0 或更高版本」而拒绝加载——市场里索引再对，也一个都装不上。

现在比较前先剥掉 `-special` 后缀，和路线脚本 `bgi_version` 的判定口径一致：`0.67.0-special.x` 视为 `0.67.0`。

### 这类问题以后不会悄悄复发

- 设置卡片抽成了独立控件 `View/Controls/SpecialSettingsCards.xaml`，页面只留一行引用，上游覆盖 XAML 也只丢这一行
- 日志成员搬到 `CommonSettingsPageViewModel.Special.cs`，日志策略搬到 `Core/Special/SpecialLogging.cs`，都在保留清单里
- `patch_special.py` 新增两节自愈：补设置页引用、补 App 里的远程任务注册与日志增强；锚点对不上直接非 0 退出，不再「跑成功但功能没了」
- `verify_special.py` 增加 4 项存在性检查 + 8 项标记检查，缺一个当场报错

### 开发文档

仓库 `Docs/` 下补了四份，写代码时可以直接对着抄：

- `development/script-json.md`：路线任务 JSON 全字段、四种点类型、七种移动方式、19 个动作及 `action_params`
- `development/script-js.md`：manifest 字段、宿主对象与全局函数清单、库与异步、设置页、`http`/`file` 白名单
- `development/plugin-dev.md`：`ocr` / `teleport` 两个扩展点、`plugin.json`、最小实现、打包与发布
- `api/README.md`：官方 wiki 与特别版独有能力对照

另修正了插件标识的写法：`id` 只允许小写字母、数字、下划线（`^[a-z][a-z0-9_]{0,31}$`），带连字符的 `ppocr-v5` 装不上，应为 `ppocr_v5`。
