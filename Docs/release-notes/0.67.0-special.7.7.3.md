## 本版改动

### 插件市场

插件页拆成三个页签：**插件市场**、**已安装**、**功能选择**。

市场从一份 `index.json` 读插件列表，卡片上直接看到简介、作者、版本和状态——没装显示「安装」，装过旧版显示「更新 1.0.0 → 1.1.0」，先装了更高版本则提示降级。

- 下载完先校验 SHA-256，对不上直接拒绝安装。插件和主程序同权限，这一步没有开关。
- 索引里写了 `min_host_version` 的，当前版本不够时按钮变「不可安装」并写明原因。
- 安装走的是和「从文件安装」完全相同的路径，所以启用开关、设置弹窗、卸载行为都一致。
- 搜索框按名称、作者、标签、分类做多词匹配；分类下拉从索引里自动汇总。
- 索引地址可以在「市场设置」里改，指向镜像或自建源都行，不用等新版。

刚上线时市场是空的——收录流程和索引格式写在仓库的 `plugin-market/README.md`。

### 标了版本号的路线不再被拒绝

之前所有带 `bgiVersion` 的社区路线在特别版上都会报「版本号要求 0.67.0 大于当前 BetterGI 版本号」，直接拒绝运行。原因是 `0.67.0-special.x` 在 SemVer 里算 `0.67.0` 的预发布版，排序反而更小。

现在比较前会去掉 `-special` 段，只比内核版本：`0.67.0-special.7.7.3` 视为 `0.67.0`，要求 `0.67.1` 的路线照样会挡。

### 界面

- **插件页**：三个页签替代原来一路往下滚的长页；市场卡片、空状态、错误提示各自成型。
- **AI 助手页**：加了页头说明；沙箱目录换成统一样式的输入框；任务输入和运行记录包上描边，深色主题下不再是一块发白的长条。
- **游戏内小面板**：快捷键改成胶囊标签，输入框有了占位提示，没有对话时给一句能直接照抄的例子；发送按钮悬停变亮而不是变灰。
- **搜索结果页**：结果按分组装箱，条目带箭头和悬停反馈；顶部可以就地重搜，也有返回按钮。
- **米游社扫码窗**：二维码加了投影和留白，右侧补上「扫码 → 确认」的步骤说明。

### 其它

- 生成诊断包时读日志不再报「文件正被另一个进程使用」。
- 同步脚本会保住特别版的版本号，上游把 csproj 版本改成什么都不会影响这一版之后的本地产物。
