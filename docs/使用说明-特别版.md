# BetterGI 特别版 使用说明

> 这是给 `BGI-quest-scripts` 特别版写的上手指南。官方文档讲的功能这里不再重复，只讲特别版多出来的东西和最容易卡住的地方。

## 1. 这是什么

特别版 = 官方 BetterGI + 三样东西：

| 多出来的 | 干什么的 |
|---|---|
| 本地 AI 助手 | 用一句话下任务，模型自己挑内置任务或脚本 |
| 游戏内助手面板 | 在游戏上按 `Ctrl+Alt+A` 唤起，不用切回桌面 |
| 录制路线比对 | 用官方客户端里的真人录制路线校验脚本路径 |

客户端本体和官方一致，只是多了这些入口。不喜欢可以完全不碰，用起来和原版一样。

## 2. 安装

1. 从 Release 下 `BetterGI_v*_special_Setup.exe`，双击选目录解压，装完自动启动。
2. 也可以下 `.7z` 手动解压。**不要**把特别版覆盖到已有的官方版目录上，两者配置文件格式一致但版本号不同，容易互相顶掉。
3. 第一次启动会在同目录生成 `User/`、`Repos/`、`Logs/` 三个目录。`Logs` 里是排错要用的日志。

## 3. 三分钟跑起来

### 3.1 配模型

侧边栏「AI 助手」→ 服务设置：

| 项 | 说明 |
|---|---|
| 服务协议 | `openai`（OpenAI 兼容，DeepSeek / 通义 / 智谱 / Kimi / Ollama / LM Studio 都走这个）或 `anthropic` |
| 服务地址 | OpenAI 兼容填到 `/v1`，例如 `https://api.deepseek.com/v1`；Anthropic 填根地址 |
| 模型名 | 必须支持工具调用。`deepseek-chat`、`qwen2.5:14b`、`glm-4` 都可以；纯聊天模型下不了任务 |
| 密钥 | 本机回环地址（`127.0.0.1`、`localhost`）可以留空，跑 Ollama 就是这样 |

配完点「测试连接」，能返回一句话就说明通了。总开关打开后，助手才会真正发请求。

### 3.2 打开助手

游戏跑起来后按 `Ctrl+Alt+A`，屏幕右下会出现一个小面板：

- 输入框写一句话，回车发送
- 再按一次热键隐藏；点 `⚙` 跳到 AI 助手设置页
- 面板是半透明的，失焦会压暗，不挡战斗信息

### 3.3 说人话就行

```
把今天的体力清掉
领一下每日和邮件
跑「第七章第五幕」脚本
打三次「深入风龙废墟」，用浓缩树脂
现在有没有任务在跑
```

模型会显示它打算做什么，然后调用工具。你能看到每一句它说的话和每一步动作，不用猜。

## 4. 助手到底能做什么

它手里只有 7 个动作，都是 BGI 自己的接口，不是模拟键鼠：

| 动作 | 作用 |
|---|---|
| `list_tasks` | 列出内置任务，按组过滤 |
| `describe_task` | 看某个任务的参数模板 |
| `run_task` | 下发内置任务并执行 |
| `task_status` | 查当前进度、上次失败原因 |
| `stop_task` | 停止当前任务 |
| `list_scripts` | 列出 `User/JsScript` 里的脚本 |
| `run_script` | 跑一个 JS 任务脚本 |

外加一个文件沙箱，可以让它读日志、写笔记，范围限制在设置的沙箱目录内。

**它不会做的**：改你的配置、删你的文件、绕过任务锁、在游戏里乱点。写文件和执行命令默认关着，需要自己在设置里开。

### 限制

- 单次会话最多 16 步（一步一次工具调用），超过就停。复杂任务拆成两句说更稳。
- 单次超时 300 秒。
- 每次都是独立会话，它**不记得**上一轮说过什么。所以「再跑一次」这种话它听不懂，要重说一遍。
- 下发失败时它会把原因带回来（比如「未找到一条龙配置默认配置」），照着改就行，别原样重试。

## 5. 脚本仓库打不开怎么办

这是反馈最多的问题，先说结论：**通常不是网络问题，是安装包缺了前端页面**。

打开脚本仓库时窗口一片空白或直接报错，先看 `Logs/better-genshin-impact*.log` 里有没有这两行：

```
System.IO.DirectoryNotFoundException: Could not find a part of the path '...\Repos\bettergi-scripts-list'
软件内网页初始化失败 ... 0x80070003
```

- 第一条：本地仓库还没同步过。新版会在后台自动拉一次，等十几秒重开就行。
- 第二条：安装包里缺 `Assets\Web\ScriptRepo`。用最新安装包覆盖安装即可；旧版本没有兜底页，只能看到白屏。

手动补救：

1. 「设置 → 通用」→「更新脚本仓库」，等进度条走完。
2. 网络不通就切渠道：默认走 CNB（`cnb.cool`），国内可直连；GitHub 源需要代理。
3. 都不行就用同页的「手动导入本地脚本仓库（zip）」，zip 到 [cnb.cool/bettergi/bettergi-scripts-list](https://cnb.cool/bettergi/bettergi-scripts-list) 下载。

## 6. 剧情脚本与路线

- 任务脚本在 `User/JsScript` 下，按章节分目录。跑之前先确认脚本目录在「JS 脚本」页能看到。
- 生成器产出的路线里有一部分只有 1 个坐标点，那是**任务提示点**，不是能走的路。新版遇到这种段会跳过并告警，不会再把角色直接怼到副本门口。
- 想自己补路线：用「录制回放」录一遍，保存成 `pathing/*.json`，脚本会优先用你录的那条。

## 7. 常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 面板发完任务就卡住，日志刷「前台不是原神，暂停」 | 面板抢了焦点 | 新版已自动归还焦点；旧版先手动点一下游戏窗口 |
| 传送提示「可能是传送点未激活」 | 多数是上面那条焦点问题的连带结果 | 同上，先解决焦点 |
| 助手说「未找到一条龙配置」 | 你的配置名不叫「默认配置」 | 让它先 `list_tasks`，或把配置名告诉它 |
| 角色识别成 `Mosasaurus`、`PlayerGirlCostumeCWXR` | 队伍栏没裁对，超宽屏或 UI 缩放导致 | 把 UI 缩放调回 100%，或用 16:9 分辨率 |
| 热更新检查失败 | GitHub 直连超时 | 新版走三级镜像回退；全失败时按弹窗给的地址手动下载 |
| 日志里同一条警告刷屏 | 旧版没做抑制 | 新版相同行只留一条并标「重复 N 次」 |

## 8. 日志与反馈

日志在 `Logs/better-genshin-impactYYYYMMDD.log`，按天滚存，保留 21 天。

提问题时带上：

1. 当天日志（整份，不要只截一段）
2. 出问题的时间点
3. 当时在跑什么任务

日志格式是 `[时间] [级别] [实例] 来源 | 消息`，一行一条，异常单独起段，方便直接搜关键字。

## 9. 更新与回退

- 特别版的版本号形如 `0.67.0-special.4`，`special.N` 是构建号，每发一次加一。
- 客户端内「检查更新」只认特别版的 Release，不会把你升回官方版。
- 想回退：保留上一版安装目录，或从 Release 下旧的 `special.4` 覆盖。配置在 `User/config.json`，两版通用。
