# 任务脚本可跑性报告

由 `tools/quest/script_readiness.py` 生成。判据：一段路线里有几个点。

- **0/1 个点** = 任务提示坐标，不是能走的路线。脚本运行时会跳过并打警告，不会再把角色直冲过去（旧版会跑到副本门口这类地方，看起来像「脚本错位」）。
- **2 个点以上** = 能生成行走路线。地形是否顺畅、锚点远不远另说。
