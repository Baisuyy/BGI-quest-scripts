# 路线优化报告

用 `data/official_routes.json` 里 1321 个真人录制点校验仓库路线，共 270 段。

## 〇、结论先说

**本轮替换 0 段。** 录制数据与任务路线在空间上几乎不重叠：270 段里只有 2 段离录制线 100m 以内、18 段在 200m 以内，其余 176 段在 500m 开外。

录制路线集中在 Boss 点和地脉花采集点，任务是主线剧情点，两者不在同一片区域。所以「沿录制路径重算」这条路走不通——不是算法不行，是样本不在场。

录制数据改用在两处更实在的地方：

| 用途 | 产物 | 效果 |
|---|---|---|
| 路网可信边 | `tools/pathing/graph.json` 的 `origin=1` 边 | 709 条边、28 km，占路网总长 45%，A* 优先走这些 |
| 实测传送锚点 | `data/anchor_plan.json` | 38 段找到真人用过的锚点，另 2 段确认无锚点可用 |
