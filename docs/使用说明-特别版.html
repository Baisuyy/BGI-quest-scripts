BetterGI 特别版 使用说明

官方客户端加三样东西：本地 AI 助手、游戏内对话面板、录制路线比对。这份文档只讲多出来的部分和最容易卡住的地方。

Windows 10 / 11 .NET 10 版本 0.67.x-special.N 热键 Ctrl+Alt+A

这是什么

特别版和官方版是同一份客户端代码，多出来的入口都挂在侧边栏，不用可以完全不碰。

新增
本地 AI 助手
一句话下任务，模型自己挑内置任务或用户脚本，不模拟键鼠。
新增
游戏内面板
按 Ctrl+Alt+A 唤起，不用切回桌面；发完任务自动把焦点还给游戏。
新增
录制路线比对
用官方客户端里的真人录制路线校验脚本路径，标出偏差过大的段。

安装

  1. 从 Release 下 BetterGI_v*_special_Setup.exe，双击选目录，装完自动启动。
  2. 也可以下 .7z 手动解压。首次启动会生成 User/、Repos/、Logs/ 三个目录。
  3. 排错要用的日志就在 Logs/better-genshin-impactYYYYMMDD.log。
!
不要把特别版覆盖到已有的官方版目录上。配置文件格式一致，但版本号不同，互相顶掉之后两边都认不出自己的更新。

三分钟跑起来

1. 配模型

侧边栏「AI 助手」→ 服务设置：

项怎么填
服务协议openai（OpenAI 兼容：DeepSeek / 通义 / 智谱 / Kimi / Ollama / LM Studio）或 anthropic
服务地址OpenAI 兼容填到 /v1，如 https://api.deepseek.com/v1；Anthropic 填根地址
模型名必须支持工具调用。纯聊天模型能回答，但下不了任务
密钥本机回环地址（127.0.0.1 / localhost）可留空，跑 Ollama 就是这样

配完点「测试连接」，能返回一句话就是通了。总开关打开后助手才会真正发请求。

2. 唤起面板

游戏跑起来后按 Ctrl+Alt+A，右下角出现小面板：输入一句话，回车发送；再按一次隐藏。

3. 说人话

把今天的体力清掉
先看一下你有哪套一条龙配置。
[1/16] 调用 list_tasks → 找到 3 个配置
用「日常」这套，树脂留给「深入风龙废墟」，现在开始。
[2/16] 调用 run_task → 已下发，任务在后台运行

模型说的每句话和每步动作都会分色显示：白色是它说的话，灰色小字是工具调用，绿色是结果。

发完消息面板会把前台让给游戏窗口。这是必须的——BGI 的任务侧发现前台不是原神就会暂停，传送这类连续点击会全部落空。

它能做什么

助手手里只有 7 个动作，全部走 BGI 自己的任务接口，不是模拟键鼠：

动作作用
list_tasks列出内置任务，可按组过滤
describe_task看某个任务的参数模板
run_task下发内置任务并执行
task_status查进度、上次失败原因
stop_task停止当前任务
list_scripts列出 User/JsScript 里的脚本
run_script跑一个 JS 任务脚本

另有一个文件沙箱，可以让它读日志、写笔记，范围限制在设置的沙箱目录内。写文件和执行命令默认关闭，需要自己开。

限制

  • 单次会话最多 16 步（一步一次工具调用），复杂任务拆成两句说更稳。
  • 单次超时 300 秒。
  • 每次都是独立会话，不记得上一轮说过什么。「再跑一次」它听不懂，要重说。
  • 失败时会把原因带回来，比如「未找到一条龙配置」，照着改就行，别原样重试。

脚本仓库打不开

反馈最多的一个问题。先说结论：通常不是网络问题，是安装包缺了前端页面。

窗口一片空白或直接报错时，先在日志里搜这两行：

# 情况一：本地仓库还没同步过
System.IO.DirectoryNotFoundException: Could not find a part of the path
  'E:\BGI-SE\BetterGI\Repos\bettergi-scripts-list'

# 情况二：安装包缺 Assets\Web\ScriptRepo
软件内网页初始化失败 ... SetVirtualHostNameToFolderMapping
System.IO.DirectoryNotFoundException: 系统找不到指定的路径。 (0x80070003)
×
第二种情况旧版只能看到白屏：WebView2 找不到目录，初始化直接抛异常，页面上什么都不显示。新版会退成一张说明页，把缺什么、放哪里写清楚。

手动补救

  1. 「设置 → 通用」→「更新脚本仓库」，等进度条走完。新版打开仓库页时也会在后台自动补一次同步。
  2. 网络不通就切渠道。默认走 CNB（cnb.cool），国内可直连；GitHub 源需要代理。
  3. 还不行就用同页的「手动导入本地脚本仓库（zip）」，zip 到 cnb.cool/bettergi/bettergi-scripts-list 下载。

剧情脚本与路线

  • 任务脚本在 User/JsScript 下按章节分目录，跑之前在「JS 脚本」页确认能看到。
  • 生成器产出的路线里有一部分只有 1 个坐标点，那是任务提示点，不是能走的路。新版遇到会跳过并告警，不会再把角色直接怼到副本门口。
  • 想自己补路线：用「录制回放」录一遍，存成 pathing/*.json，脚本会优先用你录的那条。
i
如果你看到脚本「跑歪了」，先看日志里有没有「只有 N 个点，是任务提示点而非路线」。有的话不是坐标算错，是那段本来就没有可行走路网。

常见问题

现象原因怎么办
面板发完任务就卡住，日志刷「前台不是原神，暂停」 面板抢了焦点 新版已自动归还焦点；旧版先手动点一下游戏窗口
传送提示「可能是传送点未激活」 多数是上面那条的连带结果 先解决焦点，再重试
助手说「未找到一条龙配置」 你的配置名不叫「默认配置」 让它先 list_tasks，或把配置名告诉它
角色识别成 Mosasaurus、PlayerGirlCostumeCWXR 队伍栏没裁对，超宽屏或 UI 缩放 UI 缩放调回 100%，或改用 16:9 分辨率
热更新检查失败 GitHub 直连超时 新版走三级镜像回退；全失败时按弹窗给的地址手动下
日志里同一条警告刷屏 旧版没做抑制 新版相同行只留一条并标「重复 N 次」

日志与反馈

日志在 Logs/better-genshin-impactYYYYMMDD.log，按天滚存，保留 21 天。格式是一行一条：

[22:44:32.151] [WRN] [Primary:S2:P12304] BetterGenshinImpact.GameTask.Common.TaskControl | 前台是 BetterGI，暂停

提问题时带上：当天整份日志、出问题的时间点、当时在跑什么任务。只截一段经常看不出前因后果。

更新与回退

  • 版本号形如 0.67.0-special.4，special.N 是构建号，每发一次加一。
  • 客户端内「检查更新」只认特别版 Release，不会把你升回官方版。
  • 回退：留着上一版安装目录，或从 Release 下旧的 special.4 覆盖。配置在 User/config.json，两版通用。
